# 小宇宙播客

## 数据源说明

小宇宙是国内最大的播客平台，适合发现深度需求和技术趋势。播客内容通常比图文更深，能挖到文章里看不到的细分需求。

## 目标页面

- 小宇宙搜索结果页（按关键词搜索）
- 热门播客/热门单集
- 特定播客的评论区

## 采集策略

1. 用 DrissionPage 访问小宇宙搜索页
2. 优先 listener 监听搜索接口的响应体
3. 降级方案：DOM 提取播客卡片（标题、主播、播放量、评论数）

## 重点关注的数据

- 播客标题/简介中的"怎么做""如何解决""工具推荐" → 直接需求
- 评论区高赞提问 → 真实痛点
- 近期新增播客的方向 → 趋势信号

## 特殊处理：播客内容提取

对于评分较高的机会，可以进一步：
1. 进入播客详情页
2. 尝试 listener 监听音频文件链接或字幕/文稿接口
3. 如果能拿到字幕文本，用 AI 提取其中提到的痛点和需求
4. 拿不到字幕则跳过（不强制要求处理音频）

## 产出格式

阶段一输出原始采集 JSON；进入 AI 过滤和评分后，再整理为 `templates/opportunity-card.md` 对齐的结构。

## 注意事项

- 小宇宙反爬中等，DrissionPage + 随机延迟即可
- 播客数据更新频率低，每周采集一次足够
- 评论数比播放量更能反映真实互动
