# 小红书

## 数据源说明

小红书是国内最大的生活方式分享平台，适合发现 C 端用户需求和生活类商业机会。

## 目标页面

- 小红书搜索结果页（按关键词搜索）
- 热门话题/趋势页
- 特定品类下的爆款笔记

## 采集策略

1. 用 DrissionPage 访问小红书（需登录态获取完整搜索结果）
2. 优先 listener 监听搜索结果接口（Note Search API）
3. 降级方案：DOM 提取笔记卡片（标题、点赞数、收藏数、评论数）

## 重点关注的数据

- 搜索结果按"最新"排序 → 刚在涨的需求
- 高赞笔记的评论区 → 用户反复问的问题
- 笔记中的"求推荐""有没有""哪里可以" → 直接的需求信号

## 产出格式

阶段一输出原始采集 JSON；进入 AI 过滤和评分后，再整理为 `templates/opportunity-card.md` 对齐的结构。

## 注意事项

- 小红书反爬较严，必须用 DrissionPage 模拟真实浏览器
- 操作间加随机延迟（1-3秒），避免触发风控
- 未登录时搜索结果有限，建议持久化登录态
